# Addon: Candle Structure Filter

## SKU
- `addon_candle_structure`

## Unlocks
- Candle structure pre-entry filter modes.

## Related inputs
- `Candle_Timeframe`
- `Candle_Strategy_Type`
- `Candle_Strategy_Shift`
- `Candle_Strategy_Depth`

## Addon required when
- `Candle_Strategy_Type != OFF_CANDLE_STRUCTURE`.

## Missing entitlement behavior
- EA startup is blocked with a missing-addon chart message.
