# Addon: Time Filter Session Manager

## SKU
- `addon_session_time_filter`

## Unlocks
- Session windows for Asia, London, and New York.
- Session allow/force-close behavior.

## Related inputs
- `Session_Asia_Filter_Mode`
- `Session_Asia_Filter_Time_Range`
- `Session_London_Filter_Mode`
- `Session_London_Filter_Time_Range`
- `Session_NewYork_Filter_Mode`
- `Session_NewYork_Filter_Time_Range`

## Addon required when
- Any session mode is not `SESSION_FILTER_OFF`.

## Missing entitlement behavior
- EA startup is blocked with a chart message listing missing addons.
